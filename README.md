# .github

このリポジトリでは、taketake-dev が所有するリポジトリで使う GitHub の共通テンプレートと案内を管理します。

- `.github/ISSUE_TEMPLATE/`: バグ報告と機能・改善の提案
- `PULL_REQUEST_TEMPLATE.md`: プルリクエストのテンプレート
- `CONTRIBUTING.md`: 貢献に関する共通の案内

各リポジトリに独自のファイルや設定がある場合は、そちらが優先されます。詳しくは [GitHub のドキュメント](https://docs.github.com/ja/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)を参照してください。
